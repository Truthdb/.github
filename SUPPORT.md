# Support

## Where to ask for help

- GitHub Issues: for bug reports and actionable work items
- GitHub Discussions (if enabled): for questions, usage help, and design discussion

## What to include

- What you’re trying to do
- What you expected vs what happened
- Logs and configuration (redact secrets)
- OS + relevant versions (Rust toolchain, Node, etc.)

## Security issues

Do not report security vulnerabilities in public support channels. See [SECURITY.md](SECURITY.md).
