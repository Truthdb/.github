# Security Policy

## Supported versions

Security fixes are applied to maintained branches. If you are unsure whether a version is supported, report the issue and we will advise.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Preferred reporting method:
- Use GitHub Security Advisories for the affected repository ("Report a vulnerability" in the Security tab).

If Security Advisories are not available:
- Contact the maintainers privately.

## What to include

- A description of the issue and potential impact
- Steps to reproduce (proof-of-concept if available)
- Affected component(s) and version/commit
- Any mitigations you’re aware of

## Response expectations

We aim to acknowledge reports within a reasonable time and will coordinate a fix and disclosure timeline with the reporter.
